# ✈️ Multi-Agent Travel Planner

An AI-powered travel planning dashboard built with **CrewAI** and **Streamlit**. This application coordinates a specialized crew of AI agents to research destinations, build custom day-by-day itineraries, optimize budgets, discover local gems, and export comprehensive travel guides in PDF or Markdown format.

---

## 🌟 Key Features

* **Multi-Agent Orchestration:** Powered by CrewAI, breaking complex travel planning into coordinated specialist tasks.
* **Interactive Dashboard:** Modern Streamlit interface with dynamic input parameters, step-by-step progress tracking, and day-by-day tabbed views.
* **Budget Optimization:** Real-time financial estimation and allocation tailored to your input budget.
* **Local Insights:** Recommends authentic dining spots, cultural etiquette, and off-the-beaten-path experiences.
* **Export Options:** Instantly export your tailored travel plan as a formatted **PDF** or clean **Markdown** document.

---

## 🤖 The AI Crew

| Agent | Role & Responsibility |
| :--- | :--- |
| **🔍 Travel Research Specialist** | Gathers essential destination logistics, travel advisories, and local geography. |
| **💰 Budget Analyst** | Breaks down lodging, food, and activity expenses based on target parameters. |
| **📅 Itinerary Planner** | Synthesizes logistics into an optimized, realistic day-by-day sequence. |
| **📍 Local Recommendation Expert** | Surfaces authentic culinary, cultural, and hidden gem recommendations. |
| **📝 Final Review Editor** | Ensures consistency, fixes overlapping schedules, and formats the output. |

## 🚀 Getting Started

### Prerequisites

* **Python 3.10+**
* An API Key for your LLM provider (e.g., OpenAI API Key)

### Installation

**Clone the Repository:**
   
   git clone [https://github.com/your-username/travel-planner-crew.git](https://github.com/your-username/travel-planner-crew.git)
   cd travel-planner-crew


💻 Usage
Launch the Streamlit application:

streamlit run app.py
